Team cardsheet 1 · back
Roles

Four roles, one each

Developer — holds the tool
A green. Installs the baseline CLI on a personal account and makes it write. Types when the intern writes; everyone else instructs. Owns the failure log's technical lines.
Product manager — holds the brief
Whoever would enjoy talking to her most. Briefs the intern with who it is for and why. Types the last section. Owns PRD v0 this week.
Tester — holds the bar
Turns the four criteria into criteria.md, each with the question the owner would ask to check it. Keeps the failure log during the chapter. Runs the audit of the partner's chapter.
Deployer — holds the repository
Creates the team repository from the template, adds the team, commits the trust pages, article-v0.md, failure-log.md, criteria.md, and the card photos. At least amber.

Everyone is a researcher.

Teams of five double the tester or the developer, never a role that holds a single file.

Rolessheet 2 · front
Setup

Four jobs, one per role

  • Developer — install [baseline CLI], sign in on a personal account, make it list an empty folder, then write your trust page to a file. If your machine refuses: [cloud development environment]. If that refuses: the chat interface on the same account, today only. Log whatever failed — first line of the failure log, and it counts.
  • Deployer — accept the invitation to [classroom organisation], create the team repository from the template, add the team. Do not fill the PRD or the decision log yet.
  • Tester — the four criteria (clear · accurate · responsible AI covered · useful to an owner) into criteria.md, in your words, each with the question she would ask.
  • Product manager — set up [team chat] with the partner team as guests; hold the persona and the frame.
The data rule. Public sources and your own writing may go through the tool. Interview material — transcripts, quotes, names — may not, ever: a free tier may train on it. Today's owner is fictional. Next week's is not. Nobody approaches a real company until the consent text is signed off by the research lecturer.

Any other agentic CLI with hooks, project files and MCP is allowed at your own cost. It gives no advantage in assessment; the criteria are written so it cannot.

Socratic bank, out of character · 1:18

  1. Point at one sentence nobody read before you accepted it.
  2. Which number could you verify right now? Which not?
  3. What did you ask the intern that it could not have known?
  4. Which failure-log line would be in the chapter if nobody had caught it?

Never "good", never "yes", never "you might". "Is this right?" → question 2.
