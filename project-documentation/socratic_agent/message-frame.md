# The frame every message to a team gets

The questioner writes the questions; this file writes the words around them, so
that every team gets the same opening and the same closing every week and no
run can invent a friendlier or a colder one. `{team}`, `{week}` and
`{documents}` are filled in by run_documents.py. The section between the two
`---` lines is the opening; the section after the second is the closing.

---
Questions for {team}, week {week}, about your {documents}.

These are questions, not feedback. Nobody is grading this message, and there is
no answer key behind it. Take the questions into your next revision, and note in
your portfolio which one changed what.

---
No reply is expected. Next week's questions will read next week's document
against this one.
