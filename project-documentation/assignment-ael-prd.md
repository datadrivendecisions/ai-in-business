# AEL — Week 1 assignment: Product Requirements Document (first draft)

*Minimal prompt for the first iteration. To be elaborated later if we want.*

Your team will build an agentic platform whose job is to help you research and produce a **handbook about the state of AI for SMEs** — one new published page each week.

Write a **first-draft Product Requirements Document** for that platform. Keep it to **1–3 pages**. Cover:

1. **Problem and users** — what the platform is for, and who uses it (your research team; and, downstream, the SME owner who reads the handbook).
2. **What it must let a user do** — the path from raw source material to a published handbook page.
3. **Output qualities** — what a good handbook page produced by the platform looks like.
4. **Known constraints** — you direct an agentic CLI rather than hand-code; reuse the existing wiki/site rather than build new infrastructure; a non-coder must be able to run it; every automated step needs a manual fallback.
5. **Out of scope (for now)** — what you are deliberately not building yet.
6. **Open questions and assumptions.**

This is a starting point. You will revise it as you build.

**Hand in:** one document per team, [where], by [when].
**The bar:** a reader can tell what you're building, for whom, and how you'll know it works.
